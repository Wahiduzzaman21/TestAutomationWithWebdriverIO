# TestAutomationWithWebdriverIO
Test Automation Project with WebdriverIO

Steps
# Install node js latest version from https://nodejs.org/en/. 
# Clone the link (https://github.com/Wahiduzzaman21/TestAutomationWithWebdriverIO.git) provided OR download the code from (https://github.com/Wahiduzzaman21/TestAutomationWithWebdriverIO)
# open command prompt and navigate to directory where code has been downloaded
# type npm install in command prompt and press ENTER
# after installation successfully then type npm test in cmd and press enter
# Automation code will run successfully. Ensure that corresponding machine has Chrome browser.
